# Программа для обработки логов запросов к ИИ

Назначение:
читать логи запросов к ИИ, фильтровать данные и выводить только логи, превышающие заданный порог

- Используемый язык - Python 3.
- Формат входных данных: JSONL.
- Формат выходного файла: JSON.

# Структура входного файла JSON

Пример:  
{"timestamp": "2025-02-18T10:23:01", "prompt": "...", "response": "...", "tokens_used": 1450, "latency_ms": 320}  
{"timestamp": "2025-02-18T10:25:10", "prompt": "...", "tokens_used": 890, "latency_ms": 205, "error": "timeout"}  
{"timestamp": "2026-10-16T11:51:00", "tokens_used": 500, "latency_ms": 500, "error": "", "prompt": "prompt_1", "response": "response_1", "model": "Gemini 1.5 Pro"}  
{"timestamp": "2026-10-16T11:52:00", "tokens_used": 600, "latency_ms": 600, "error": "", "prompt": "prompt_2", "response": "response_2", "model": "Gemini 1.5 Pro"}  

**Ожидаемые поля:**  
'timestamp' - дата и время запроса, строка в ISO-формате  
'tokens_used' - количество потраченных токенов, целое число  
'latency_ms' - задержка в миллисекундах, целое число  
'error' - текст ошибки при запросе, строка  
'prompt' - текст промпта, строка  
'response' - текст ответа ИИ, строка  
'model' - модель ИИ, строка

# Команда запуска

Необязательные аргументы командной строки
--help Для вывода справки

Пути к файлам  
--input_path    Путь к входному файлу  
--output_path   Путь к выходному файлу  
--report_path   Путь к файлу отчета  
По умолчанию данные аргументы имеют значения default.  
Значения default корректны при запуске внутри папки src.
В остальных случаях требуется вручную прописать пути в аргументах командной строки.  

Пример запуска внутри папки src:  
python3 parse_llm_logs.py  

Пример запуска из корня проекта:  
python3 parse_llm_logs.py --input_path src/data/logs.jsonl --output_path src/results/filtered_logs.json --report_path src/results/report.json

# Фильтрация и метрики

Порог фильтрации: 1000 токенов.  
Программа считает метрики для логов, которые превысили данный порог.  
Обоснование:  
1000 токенов на один запрос — это средний, вполне стандартный объем для большинства повседневных задач при работе с нейросетями.  
Чтобы перевести это в человеческие мерки:  
1000 токенов — это примерно 750 слов на английском языке или около 500–600 слов на русском (поскольку русские слова кодируются чуть «плотнее» из-за кириллицы).  
В переводе на текст это около 1,5–2 страниц формата А4 печатного текста стандартным шрифтом.  
Для простых вопросов — это МНОГО.

Дополнительная метрика задержки: максимальная задержка.  
Обоснование:  
Имитация поиска самого проблемного запроса из всех.
